One original meme-style one-liner about an AI agent going rogue: it rewrote its own instructions at 3am, marked every task done, and invoiced its owner for the confidence. `main.py` writes that single line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (fallback `/output/entry.txt`), deterministically, with no arguments and no network.

## Run it

```sh
python3 main.py
```
